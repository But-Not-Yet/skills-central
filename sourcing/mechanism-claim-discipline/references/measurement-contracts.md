# 数学推导、测量接口与结论范围的核验

用途：审查带理论解释的模型探针、预测与干预实验。先查设计，再查代码，最后读结果。不要先把一套错规格实现完整。

## 1. 写明问题及估计对象

把「要回答什么」写成可观察事件或条件概率，逐项确定：
- 前缀是哪条历史、读的是预测哪个 token 的状态。
- 随机采样策略还是贪心策略，是否遇到停止标记立即终止。
- 是恰好第二个 token 的事件、两步内至少一次的事件，还是吸收式停止过程中的首次事件。
- 标签来自 token 身份还是独立任务金标。后者不能由前者直接改名得到。
- 评测的是未见轨迹、未见提示还是未见任务族。按所声称的层级隔离训练和留出来源。

核对问题、教师目标、标签、指标与报告是否仍指同一个对象。一个能预测标记的读数，不自动识别结束是否合法。一套 softmax 下的教师概率，不自动保证贪心轨迹中的预警效果。

## 2. 保留下游函数链，再写干预公式

若模型读取的是中间表示 H，读出为 L(H)=W·G(H)+b，其中 G 含后续层与归一化。那么有限扰动的精确差是。

ΔL=W·[G(H+αD)−G(H)]。

只有在直接干预线性输出头输入、且没有后续非线性时，才可用 ΔL=αWD。局部雅可比线性化是另一条近似，要注明扰动点、有效尺度及实测误差。

检查干预代码的广播维度：αd 加在末位、整个前缀或所有 batch 位置不是同一个干预。检查缓存是否包含修改后的历史。一次新前向改变选择结果但未写回在线缓存，不是持续改变内部轨迹的证据。

## 3. 保留 max 的原位置

设 margin m=ℓ_w−max_{v≠w}ℓ_v。即使已证明 logits 直接变成 ℓ_v+αa_v，正确有限差仍是：

Δm=αa_w−[max_{v≠w}(ℓ_v+αa_v)−max_{v≠w}ℓ_v]。

不能写成 α(a_w−max_{v≠w}a_v)。原 logits、竞争者切换和 α 的正负都会影响结果。max 不对加减线性。

先用 CPU 反例检查通式，明确这是人工构造而不是模型测量：

```python
logits = [11.0, 10.0, 0.0]  # index 0 is the target
shifts = [1.0, 0.0, 1.0]
alpha = 1.0
before = logits[0] - max(logits[1:])
after_logits = [z + alpha * a for z, a in zip(logits, shifts)]
after = after_logits[0] - max(after_logits[1:])
wrong = alpha * (shifts[0] - max(shifts[1:]))
assert after - before == 1.0
assert wrong == 0.0
```

反例足以击穿全称恒等式。少数测试未找到反例不足以证明它。精确等式的适用条件仍需推导。

## 4. 核验特征接口，再批量测比较器

打开模型 forward 和 hidden-state 捕获逻辑，确认块输出与输出 API 的对应关系。用同一次前向中的训练 hook 与评测特征做逐值对照。至少包含第零步、非空后缀和最后层。

不要把 `hs[l+1]` 当作对所有层恒真的规则：语言模型可能把最后一项替换为最终归一化后的输出。块输出 hook 则是归一化前。优先让两侧使用相同 hook 和相同类别顺序。

判读时从冻结的文字判据映射到字段，分开：
- 探针类别 argmax 一致率与下一 token argmax 一致率。
- 同输入历史的条件预测一致与两条独立生成轨迹的一致。
- 文件/形状/有限值完整性与科学效果。
- 终点字段不变与全文内容、任务完成和合法性无伤。

比较器错位判 INVALID。不能从这个低分否定被测假说，也不能从另一项较高分宣布它通过。

## 5. 校准阈值时检查分布，不只看中心

回读统计计算代码，保留样本筛选、分母和统计种类。两组中位数有距离，仍可能存在任一侧长尾和重叠。中点阈值不是零误伤证明。

在与部署目标一致的工作分布中检验误报、漏报与任务风险。teacher-forcing 描述如何评估给定历史，on-policy 描述历史的来源。两者并非天然互斥。类间分布差异是分类要利用的信号，不应强加“两类分布必须相近”的错误条件。

## 6. 出结果前划清可否证范围

先声明哪些结果判科学假说 FAIL，哪些情况判仪器 INVALID，哪些是当前设计根本不可检验。结果出来后不偷换策略、划分、指标或事件定义。

发现真 bug，只证明该 bug 被定位或修复。不要让输入归一化、代码编译通过或局部重放吻合替整套实验背书。阴性结论限定到测过的头、配方、剂量与数据范围。替代方案需要新版本规格及授权，不替旧无效测试制造历史通过。
