# 聊天里的数学排版

## When to Use（何时用）

主人要数学推导、严格定义、符号化表述，或回「看不懂」「用数学语言写」「每个公式都得编号」时。聊天与桌面预览里的公式都算。已成文的 LaTeX 文档（投稿稿、IEEEtran、编译验证）走 `latex-research-writing`，不走这份。

## 主人的格式规格（多轮纠正定下的，别再问）

1. **记号表放最前**：每个符号一行、含义写在右边。后文出现的每个字母都必须能在表里查到。他回「我看不懂」，多半是符号没定义就用了。
2. **结构 = 定义 / 命题 / 定理 / 证明 分块**，证明以 *证明.* 起、■ 收。陈述与证明分开，不许把论证混在正文散文里。
3. **每个 display 公式必须带编号**，正文只引用编号（写成 (7.4)），不写「上式」「如前所述」「前面那个」。
4. **结论先给**：开头一句话判定 + 关键编号，再展开推导。
5. **出处核不到就标【未核】**，卷期页码没把握就只给能给的，绝不补一个看起来像的。
6. 他回「什么意思？」= 要**人话重述**，不是要更多符号。先用人话把上一轮的判定重说一遍，再上形式化。
7. 反例与失效模式要写清「失败在哪一层」（维数 / 连续性 / 一致有界性 / 精度），这是他追问的重点。
8. **数学密度跟着他的情绪走，不跟着题目走**（10-14 定）。他明说讨厌推导、推导不出来、看长串符号生理厌恶。默认交付顺序：一句中文结论 → 假设清单 → 实验对象是什么 → 跟谁比赢多少。证明一律跳过，别替他补推导。他连着两轮表达厌恶，后面就不再出现 display 公式。
9. **已表态的立场不再重新论证**（10-14 定）。他说「我就是不想要数学」之后再给一段「但数学也有用」= 顶回去 = 让他更火大。他发火时：先认自己那轮的行为（辩论、递长推导），再干活，不辩解。他的标准是性能击败同行与可交付产品，不是严谨。

## 桌面渲染安全写法（实测表，写公式前照这张选）

| 写法 | 实测结果 |
|---|---|
| own-line 三段式：`$$` 独占一行 → 公式 → `$$` 独占一行，配 `\tag{n}` | 渲染，编号显示成 (n) ← **默认选这个** |
| ` ```math ` 围栏 | display 渲染，无编号 |
| 单行 `$$ … \tag{n} $$` | **失败**：`\tag` 只在 display 有效，单行 `$$` 走 inline 通道 → 屏幕原样印出 LaTeX 源码 |
| 单行 `$$ … $$`（无 `\tag`） | 渲染（inline 模式） |
| 行内 `$…$`，体内只拉丁字母与符号、汉字在外部 | 渲染 |
| 行内 `$…$`，体内含汉字 | 不渲染，转义成文字 |
| `$5` 货币写法、中文句里两个裸 `$` 夹中文 | 自动转义成文字 |

规则：

- **要编号就一律 own-line 三段式**。`\begin{cases}` / `array` / `aligned` 配 `\tag` 时同样必须 own-line，别图省事写单行。
- 中文正文里的行内公式把汉字留在公式外：写「真实数据落在 $\ell^\infty$ 里」，不写「$\ell^\infty$ 空间里」。后者把中文塞进体内，体内一带汉字就转义成文字。
- 货币与「夹中文的裸 `$` 对」出现转义，是**防整句当成一个公式**的保护，不是故障，别当 bug 汇报。
- 表格单元格里的公式未实测。要放就先跑探针，或改成 own-line 段落。
- **主人说「渲染不出来」时，先怀疑自己的写法**（十有八九是单行 `$$` + `\tag`），别先推荐插件，也别先建议 `hermes update`。桌面版内置 KaTeX，不存在「缺插件所以不渲染」。
- 渲染器行为随版本变（上游一直在改 markdown 预处理）。这张表是实测快照，与现场冲突时**重跑探针为准**，别拿这张表当永久事实压主人看到的屏幕。复现配方在 `hermes-local-ops-troubleshooting` 那份 skill 里（桌面 markdown 渲染探针：KaTeX 层 + jsdom 整链）。

## 交付形态

- 公式条数多（十几条以上）或主人要长期留档：生成 KaTeX 排好版的 HTML 交出去，编号一个都不会塌。聊天里挂 `::preview{file="…html"}`，或走 `MEDIA:` 文件卡。
- 直接在聊天里写：按上表，own-line + `\tag`。
