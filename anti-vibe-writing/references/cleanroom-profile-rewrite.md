# 净空改写器：用隔离人格给 persona/系统提示词文件去 AI 味

适用：重写 SOUL.md、MEMORY.md、USER.md 这类每轮注入的人格文件。本会话的 agent 天天读同一批文件，自己改自己=回音；解药是把手术刀换成一个只吃外部腔调的隔离 Hermes 人格，产物过审计后交主人验收替换。

## 手术室搭建（一次性）

1. `hermes profile create <name> --clone`（复制模型配置，底座与生产一致，改写结果迁回不换腔）。
2. SOUL = 外部来源卡逐字节拼接（`cat card1 card2 > SOUL.md` 后 `cmp` 核验；别手打）。卡必须是社区真实件，不是自写规则。
3. **隔离净空（关键，克隆会带进污染）**：把 profile 里 `memories/MEMORY.md`、`memories/USER.md`、整个 `skills/`、`.skills_prompt_snapshot.json` 全部 mv 进 `backups/<标记>/`——记忆和技能索引也在注入面里，不清等于没隔离。
4. 旧 SOUL 与各原件先 `.bak`。

## 手术工单（每段一张，模板固定八条）

按 `## ` 标题切段（persona 文件常只有一个 `# `，别切出一整块）。工单要求：
1. 忠实重写不是缩写：每一层意思都要在，不丢不增不删；篇幅可变但信息不减。
2. 事实原样：「」引语、[事-N] 类指针、日期裁定、数字、英文词、路径、表格行列单元格逐字保留。
3. 允许结构重排（小节顺序、列表/段落划分），前提信息不减——主人明确拍板过这条。
4. 拆破折号同位语；「不是A而是B」改直陈；句子写短、动词优先。
5. 不加 emoji、不自我表扬；只输出该节本身，从原标题开始，无前言后记。

memory 条目版工单额外三条：条目数不变、条目间分隔符逐字保留（如单独一行 §）、单条字数不超原条目（memory 有字符硬闸）。

## 批量执行

- 单发命令：`timeout 420 hermes -p <profile> chat --query-file q.txt --oneshot`（一次约 100 秒起，长段可到十几分钟——ETA 别拿短段外推）。
- 输出提取：正文在 `╭─ ☤ Hermes ─╮ … ╰─╯` 框内，`raw.split('╮',1)[1].split('╰')[0]` 再逐行剥 `│ ` 前缀；框外还有推理框，别混进去。
- 串行流水线脚本：逐段查 `out_*.md` 已存在即跳过（幂等断点续跑），产物落盘。后台进程被杀后靠这个幂等重跑，无额外成本。
- 组装：按段序拼接；样式锚段（逐字模仿对象，如样例库）直送原文不动刀。

## 哨兵自动收尾（no_agent cron）

脚本每 10 分钟一巡：段数齐 → 自动跑组装+审计 → stdout 报告叫醒主会话 → 落 done-mark 防重复；进程死且 15 分钟无新产物 → `nohup` 断点重启并通报；其余静默。投递目标必须显式 `deliver=all`/平台（TUI/桌面 origin 解析不出通道，见 hermes-local-ops-troubleshooting）。cron `script` 参数只收 `~/.hermes/scripts/` 下的裸文件名。

## 验收两件套（缺一不算完）

1. **事实保全审计**：对新旧全文（或逐条对位）做集合差——引语 `「…」`、指针 `[事-N]`、日期、数字、路径逐项核，缺项列清单；memory 版还查条目数一致与单条不超原长。
2. **指纹密度对照**：`style_fingerprint.py 旧 新`（每千汉字的破折号/「不是A而是B」/英汉比等），目标病灶指标归零且其余指标不误伤。

两件产物（组装件 + 审计）交主人过目点头后才替换生产文件；替换后各留 `.bak`。数字类指标开口前实测，别引用未跑的预估。
