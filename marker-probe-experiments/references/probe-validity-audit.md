# 探针实验的样本量与构念效度审计

交付前跑一遍的数值工具与检查清单。适用于线性探针、层间可分性、检索召回这类「小样本 + 高维特征」实验。

## 1. 分辨率与置信区间

**AUC 粒度**（离散序对计数决定的下限）：

```
step = 1 / (n_pos * n_neg)
n_pos=n_neg=3  -> 0.1111     4v3 -> 0.0833     10v10 -> 0.005
```

三折均值的最小间隔 = step/3。若观测到的各层/各条件得分只差在这个量级，排序无意义。

**AUC 的 95% CI 半宽**（Hanley–McNeil 1982 闭式，n = 每类样本数，在 AUC=0.90 处）：

| 每类 n | 3 | 5 | 10 | 25 | 50 | 79 | 100 | 200 |
|---|---|---|---|---|---|---|---|---|
| CI 半宽 | 0.286 | 0.212 | 0.145 | 0.090 | 0.063 | **0.050** | 0.044 | 0.031 |

```python
def auc_ci_halfwidth(auc, m, n, z=1.96):
    q10 = auc / (2.0 - auc)
    q01 = 2.0 * auc ** 2 / (1.0 + auc)
    var = (auc*(1-auc) + (m-1)*(q10 - auc**2) + (n-1)*(q01 - auc**2)) / float(m*n)
    return z * var ** 0.5
```

n < 20 时渐近式偏乐观，小样本改用 Fisher 精确检验算「满分是否可能偶然」：
`p_perfect = 1 / C(n_pos + n_neg, n_pos)`（3v3 → 0.05，4v3 → 0.0286）。

**规模门槛**：要分辨 ±0.05 的 AUC 差异，每类 ≥79 例。±0.10 每类 ≥21 例。低于门槛的结果标「路标」，不进判决、不进论文正文。

## 2. 有效单元计数

逐 token 落盘的 jsonl 容易把行数当样本量。判定规则：

- 真值在样本内恒定（整段同一标签）→ 有效单元 = **prompt 数**，token 行不提供额外信息。
- 真值在样本内切换 → 有效单元介于两者之间。切换点（switch event）数才是检测延迟类判据的分母。
- 报告里同时写行数与有效单元数，只报前者会被读成样本充足。

## 3. 切分泄漏检查

按索引步长切折（`idx[f::k]`）时，同一构造的不同臂常被拆到 fit/hold 两侧。检查脚本：

```python
for f in range(n_folds):
    hold = set(idx[f::n_folds]); fit = [i for i in idx if i not in hold]
    shared = {construction_id[i] for i in hold} & {construction_id[i] for i in fit}
    # shared 非空 = 留出集不含新构造，只能声称「族内泛化」
```

要声称「对新句式/新构造泛化」，必须按构造族整组切分（GroupKFold 语义）。

## 4. 构念操纵检查（2×2 因子格）

写探针训练脚本前先填这张表，任一格缺失 = 该轴没被操纵：

|  | 表面形式 A | 表面形式 B |
|---|---|---|
| 构念状态 M | 需要 | 需要 |
| 构念状态 U | 需要 | 需要 |

只填了对角线（如「字面+M」对「白话+U」）时，构念轴与表面轴完全共线，探针学到的必然是表面轴。整改：补另两条对角线，跨填充做 leave-one-filler-out，并加一个「同表面、不同构念」的对照格。

自查句：**「我的标签声称的变量，和脚本里真正改变的东西，是同一个吗？」**

## 5. 审计脚本骨架

一次跑完、输出 ASCII、不落敏感字面量：

1. 折结构：每折 fit/hold 大小与类别构成、AUC 粒度、Fisher 精确 p。
2. 容量比：参数量 ÷ fit 点数（线性探针 = (H+1)/n_fit）。
3. 得分表：逐层/逐条件的全部离散取值 + 并列计数 + 平局规则会选谁。
4. 切分泄漏：每折 shared-construction 计数。
5. 落盘数据：按显式样本 id 分组，逐样本 n / pos / neg / switch 数，与 meta 声明的 n_gen 对账。
6. 有效单元 + CI，与上面表格对照给出「够不够判」的结论。
