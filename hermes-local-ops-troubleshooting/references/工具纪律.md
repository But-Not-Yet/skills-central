# 工具纪律（主人裁定 2026-10-09）

## write_file 写闸：必须先读后写，禁止绕过校验器

- 覆盖已存在文件前，**同一回合内**先 `read_file` 读回全文（分页文件读满每一页），再调 write_file。
- 写闸（stale_write_blocked）连拦两次以内不要改用 execute_code 原生 open() 绕闸——主人明令禁止绕过校验器。正确出路：当场 read_file 全文 → 合并改动 → write_file 重试。小改动优先 patch。
- 若确需原生 open() 落盘（历史例外，不再采用），必须当场回读 + MD5 比对才算数。今后一律走 write_file 正道。
- 教训实例（2026-10-09 L1 脚本 v2）：跨回合的 read 不被写闸认账，连拦两次后小喵用 open() 绕闸落盘。被主人立规禁止。

## 句子不是动作（同日两案）

- 「点火看门狗」「现在落 v2」这类收尾句若无同回合的工具调用跟随 = 空承诺，回合自然结束。什么都没发生。规则：承诺动作的句子必须与工具调用同回合发出。被打断/被拒后，下一回合第一件事是补枪，不是解释。
